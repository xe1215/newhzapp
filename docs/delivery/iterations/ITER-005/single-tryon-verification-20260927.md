## 修复与根因

- 恢复真正的即梦 HTTP 请求、签名、异步任务查询、图片下载及云存储上传；每个任务仅保存一张结果图。
- 即梦返回的 20 位任务 ID 必须保持字符串。嵌套 JSON 解析曾把纯数字字符串转换成 JavaScript Number，损失精度。回归测试已先复现末位被改写，再验证修复。
- 自拍接口返回永久 `selfieFileId`；商品详情入口验证原图可用性，无有效自拍则保留商品选择并进入拍照/图库页。
- 试色页显示真实原图、生成中/失败可重试状态和实际结果；重试调用真实业务接口，不伪造成功。
- 推荐列表使用 active 商品真实 ID 与图片；商品图使用原有默认图回退，去掉相关图片容器中遮挡真实图的示意瓶身。商品查询失败显示提示，不静默保留空白。
