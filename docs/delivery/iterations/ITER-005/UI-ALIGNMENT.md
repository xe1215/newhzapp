## 平台适配和边界

- 照片按用户授权留空，保留图片区域尺寸；图标使用从原稿提取的本地 SVG。试色抽屉保留原稿已有商品示意图。
- 状态栏和右上胶囊使用微信原生区域，不复制网页中的假 9:41 和两个圆形按钮；顶部、底部按设备安全区适配。
- 当前 HTML 只画了两张推荐卡；第三张来自此前明确确认的三角色需求。第三张为 mock 示例，不表示真实推荐结果或实时售价。
- 抽屉按内容高度展开并保留可滚动兜底，照片区域填充剩余空间，避免照搬网页展开后底部的大块空白。
- 搜索、账户设置等 HTML 中仅弹提示的入口仍为本地提示。页面没有接入生成、支付、上传接口，也没有删除旧后端功能。
- `miniprogram/app.json` 仍保留旧页注册供后续清理任务处理；新九页导航不进入旧业务页面。

## 已执行验证

1. `node tests/issue22.test.js`、`node tests/issue23.test.js`、`node tests/issue24.test.js`：通过。覆盖页面注册/资源、画像单选多选、色号传递、商品选择、抽屉上下限及对比锁定。
2. `node tests/support/compile-design.cjs`：微信自带 WXML/WXSS 编译器编译九页通过。
3. 微信开发者工具 430 × 932 模拟器：九页已实际访问；分析页完成后读取到目标页 `kind = profile`；商品详情点击 P04 再点击 AI 试色，试色页读取到 `shade.code = P04`。首页四张商品卡可查询，主按钮宽度 386px，自拍入口 229 × 229px，相机圆钮 55 × 55px。
4. 模拟器真实 touchstart/move/end 事件：抽屉上拉后 `sheetExpanded = true`；再拖动对比区，`slider` 保持 50。展开商品图区域为 386 × 206px，对应原稿约 335 × 180px（rpx 取整存在误差）。
5. 原稿九页截图与尺寸表位于 `output/playwright/reference-*.png`、`reference-layout.json`。模拟器截图位于同目录 `*-after.png`。截图接口存在间歇超时，未获取更新截图的页面不能视为完成最终逐像素验收。
